continues to cover project code and documentation as described in
[LICENSE_POLICY.md](LICENSE_POLICY.md), including commercial code use.

Each Hugging Face weight release must carry:

1. A model card with `license: cc-by-nc-4.0` and a clear weight license section.
2. `LICENSE`: an unchanged copy of [MODEL_LICENSE.txt](MODEL_LICENSE.txt).

noncommercial redistribution rights. Updating this source document does not
